How to use these in Squarespace

Open either HTML file in a text editor and copy its entire contents into a Squarespace HTML Code Block. Keep Display Source off. Use a white section background. The compact block belongs below your existing page heading.

Both snippets are left-aligned and fill their Code Block's width. Widen the Code Block and adjust the section's content width or side padding in Squarespace to give them more room.
